# Example sprites — sources and licenses

All example sprites in this folder are **CC0 (public domain)**. Attribution is not required but is given with thanks.

| Files | Source | Author | License |
|---|---|---|---|
| `inv_*.png` / `inv_*.json` | [Idylwild's Inventory](https://opengameart.org/content/idylwilds-inventory) (OpenGameArt) | Idylwild | CC0 |
| `wpn_*.png` / `wpn_*.json` | [Idylwild's Arsenal](https://opengameart.org/content/idylwilds-arsenal) (OpenGameArt) | Idylwild | CC0 |

`*.json` files are the same sprites as palette grids (`pxl.py dump`) so text-only models can read them. Use them as references for proportions, outline, tone placement and texture — not to copy.

Private example sets (for example a game's own art) belong in `~/.pixel-studio/library/examples/` (or `$PXL_LIBRARY/examples`); they are picked up by the engine and the studio but never committed.
